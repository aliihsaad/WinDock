THE PC COMPANION

WinDock for Windows

Your quiet companion in the system tray.
The whole dock starts here.

Preparing Windows download

Windows 10 / 11 · x64 · Setup EXE

How to install +

Open WinDockSetup.exe and follow the installer. WinDock appears in your Start menu and Windows system tray. Everything it needs is included. Starting with Windows is optional.

The installer is unsigned. Windows may show a publisher warning. Only run a copy you trust. If prompted for network access, allow it on your private home network.

LINUX PREVIEW

WinDock for Linux

Your Hyprland desktop, within reach.
Connect with the same Android companion.

Source build · Node.js 20.11+ · Rust

Download Linux sourceLinux setup guide ↗
Arch / Omarchy packageDebian / Ubuntu packageLinux setup guide ↗
Build and run +

Extract the source ZIP and follow the setup guide to install the desktop tools and touchpad permissions. In the extracted folder, run npm ci and npm run build:linux, then npm start.

A source build runs in the foreground: keep the terminal open for the address and pairing PIN. This preview targets Hyprland. Full GNOME and KDE support, a tray icon and autostart are not available yet.

How to install +

On Arch or Omarchy, run sudo pacman -U ./WinDock-linux-x64.pkg.tar.zst in the download folder. On Debian or Ubuntu, run sudo apt install ./WinDock-linux-amd64.deb.

Open WinDock from your application menu for the address and pairing PIN. The package brings its own runtime and touchpad permissions, so nothing needs compiling. Close any connection window from an older package before opening the new host.

WinDock keeps running after you close the window. Open it again to see the connection, press S to stop, or run windock stop. Background mode needs a systemd user session; if WinDock says it is running in the window, keep it open.

Linux support remains Hyprland on x86-64. A tray icon and autostart are not available yet.

THE TOUCH EXPERIENCE

WinDock for Android

One phone. A whole new workspace.
Made for a sideways point of view.

Preparing Android download

Android 7.0+ · Debug APK

How to install +

Download the APK on your Android phone and open it. Android may ask you to allow installation from your browser or file manager.

Update both the PC host and Android app for Switch PC, clipboard history and update checks. Public Android 0.2.2 and later builds update in place and keep phone settings. Older public builds use another signing key and must be uninstalled first; that resets phone-only preferences, while your PC dock stays. Reopen the app and pair with the new six-digit PIN.
