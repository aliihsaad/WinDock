SETUP & HELP

A little setup.
A lot of everyday.

Choose your PC host, install the Android companion, and pair with the six-digit PIN.

Get the apps

Windows

Run WinDockSetup.exe. Open WinDock from Start, then choose Show connection info from the tray. Allow access on your private network if prompted.

Keep the tray host running while you use your phone. For an update, quit WinDock, run the new installer and reopen it. Your PC dock settings are kept.

Linux / Omarchy

Install the Arch or Debian package from the downloads section. Linux support currently targets Hyprland on x86-64.

sudo pacman -U ./WinDock-linux-x64.pkg.tar.zst

Or, on Debian / Ubuntu with Hyprland:

sudo apt install ./WinDock-linux-amd64.deb

Open WinDock from your application menu for the address and PIN. It keeps running after you close its window. Open it again for connection info; press S or run windock stop to stop the host. Background mode requires a systemd user session.

Linux requirements & source setup ↗

Android

Install the APK on an Android 7.0+ phone or tablet. Allow installation from your browser or file manager when Android asks. Connect to the same Wi-Fi as the PC, open WinDock, choose your PC and enter its PIN.

Turn your phone sideways for the dock. Swipe up for the drawer, including Switch PC, Apps, Touch & sign and Updates.

Public Android 0.2.2 and later can update in place. Older previews used another signing key and need uninstalling first; this resets phone-only preferences.

QUESTIONS & ANSWERS

A few things
before you go.

Do I need both apps?+

The Windows or Linux host runs on your PC. On your phone, use the Android app for the fullscreen experience, or open the address shown by the PC host in a browser. Both connect to the same dock.

Can I connect over USB?+

Yes. Use a data-capable cable, enable USB tethering in Android Settings, then select Connect by USB → Find USB PC. Enter the normal PIN from the Windows tray. No USB debugging is required. For wireless, select Connect by Wi-Fi. Tethering can share mobile data with Windows; turn mobile data off if unwanted.

Can the phone dim or sleep?+

Open This phone on the connection screen or Appearance → This phone · screen & sleep in the dock. Choose idle dimming and screen rest. At a timed limit the dock goes black and lets Android sleep; the phone’s own screen timeout may add a delay. These controls reduce prolonged display exposure but cannot guarantee burn-in prevention.

Does it work away from home?+

WinDock works directly over your network. In 0.2.5, if you already use Tailscale on both devices, enter the PC’s numeric Tailscale address manually in the Android app and pair with its PIN. Automatic discovery remains local-network only. WinDock does not set up a VPN or provide a hosted remote-access service.

Can I use an older Android phone?+

The Android app supports Android 7.0 and newer. Update Android System WebView if the interface has trouble loading, then turn the phone sideways for the dock.

My phone can’t find my PC. What next?+

Check that the WinDock host is running and both devices are on the same network. On Windows, open Show connection info from the tray; on Linux, open WinDock again. Read the displayed address and enter that address manually on the phone. Guest Wi-Fi and firewall settings can prevent devices from seeing each other.

How do I add apps and more pages?+

Swipe up and open Apps to pin your favorites. New pages appear as you add more than your chosen four, six, or eight icons. Hold to rearrange, and drag an icon to the edge to move it between pages.

Is an iPhone app coming?+

Yes. An iOS companion is planned, using the same dock interface and local connection to your Windows PC. It is not available to download yet, and there is no release date.

How do the keyboard and signatures work?+

Open Touch & sign in the drawer. In the Android app, supported PC text fields can open your phone keyboard automatically; the keyboard button is always available as a fallback. Words arrive when your keyboard commits them. Signatures are handwritten images: save a PNG, or paste into a PC app that accepts images. The website demo only simulates these actions.

How do I get future updates?+

On Windows, choose Check for updates from the tray. With 0.2.5, you can also open Updates in the dock drawer or Appearance, Android’s connection screen, or the Windows connection window. The app shows the installed version and whether an update is available. Downloads and installation are manual: quit the Windows host, run the new installer, and reconnect your phone. Your dock settings are kept.

How do I update the Android preview?+

The Android app has its own version and update check in 0.2.5. Install the new APK over public 0.2.2 or later to keep phone settings. Older public previews used another signing key, so uninstall those first, then install and pair again. Uninstalling resets phone-only preferences; the dock on your PC is preserved.

Can I choose a different PC?+

In 0.2.5, open Switch PC from the Android connection screen or dock drawer. Refresh finds running hosts on your local network; choose a PC and pair with its PIN. You can keep both hosts running. Forget removes a remembered PC and prevents automatic reconnection, while Refresh can find it again for an explicit choice.

How does PC clipboard history work?+

In 0.2.5, open Touch & sign → PC clipboard. Choose recent text, edit it, then tap Paste to PC with a supported text field focused on the PC. Browsing sends nothing. Windows needs history enabled with Windows + V. Linux reads a running clipboard manager, or offers the current clipboard if none is running. Images and files are excluded, and closing the panel clears its text from the phone.

What should I know before installing?+

The Windows installer is unsigned and the Android APK is debug-signed. Download the installers from this website or the official GitHub release, and check the published SHA-256 sums if you need to verify the files. An Android build signed with a different key may require uninstalling the previous one first.
