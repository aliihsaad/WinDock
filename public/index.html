          Wake another PC.

          Turn on a sleeping or shut-down computer on the same network. It needs Wake-on-LAN switched on in its BIOS and network adapter, and a wired connection works best. This PC sends the signal, so it must be on.

          On that PC, open Command Prompt, run ipconfig /all and copy the Physical Address of its network adapter.
